# Java 后端面试八股笔记

个人整理的 Java 后端面试复习笔记，覆盖 **Java 基础、集合、并发、JVM、MySQL、Redis、Spring** 七大高频模块。

内容以「面试能直接说出来」为目标：先给结论，再补原理和对比，尽量用口语化的方式记录记忆点，适合面试前快速过一遍、也适合平时查漏补缺。

> 笔记为个人学习整理，表述以理解为主，部分内容做了口语化简化，欢迎对照官方文档补充细节。

## 怎么用

1. **先过综合清单**：[Java后端知识清单](总结/Java后端知识清单.md) 按模块列出了高频问题，适合第一遍梳理知识地图。
2. **再按专题深挖**：遇到答不上来的题，跳到对应模块的笔记看原理和对比。
3. **面试前速刷**：只看每个问题下的加粗结论和对比表格，快速回忆。
4. **不会的题这样问 AI**：[提示词](提示词.md) 里是一份「从零推导」的提问模板，把题目填进去，能让 AI 从现实问题出发一步步推到结论，避免死记硬背。
