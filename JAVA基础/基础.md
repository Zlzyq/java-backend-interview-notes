# JVM内存结构

- **方法区**：共享，静态变量、方法代码、常量，线程不安全
    
- **堆**：共享，存放大量的对象，含有GC，处理不当容易OOM，线程不安全
    
- **栈**：每个线程私有的，所以无法共享，存放
    
    1. 局部变量
        
    2. 对象引用
        
    3. 线程调用方法的时候相关的信息  
        线程安全
        
- **本地方法栈**：执行native方法，因为语言不痛、操作逻辑不通，区分开来容易管理
    
- **pc寄存器**：线程任务不断切换，用于记住自己的工作进度，以便下次继续

# 接口和抽象类的区别

接口：只有方法名、传参  
抽象类：和普通类只差一个 **`abstract`**，里面的抽象方法像接口一样，只用写方法名

以下五点：

| 接口  | 抽象类                  |            |
| --- | -------------------- | ---------- |
| 继承  | 可以多个实现               | 只能单继承      |
| 状态  | 只能存放静态常量             | 字段、构造器都可以有 |
| 代码  | 抽象方法，8+后静态方法和default | 抽象方法+具体方法  |
| 定位  | can-do               | is-a       |
| 场景  | 多个类共享某种能力            | 多个类共享 属性   |

# sleep和wait的区别

|      | sleep          | wait                        |
| ---- | -------------- | --------------------------- |
| 所属类  | `Thread` 的静态方法 | `Object` 的实例方法              |
| 锁    | **不释放锁**，抱着锁睡  | **释放锁**，让别人进来               |
| 调用条件 | 任何地方都能调        | **必须在 synchronized 块/方法里调** |
| 唤醒   | 时间到自动醒         | 需要 `notify/notifyAll`，或超时   |
| 醒后状态 | 就绪，等 CPU 调度    | 先抢锁，抢到才继续                   |
| 比喻   | 当场昏睡，锁还攥手里     | 去休息区等通知，锁先交出去               |

# String 常用方法

> String 不可变，所有“修改”方法都返回**新字符串**，原字符串不动。

|                               |       |                                      |
| ----------------------------- | ----- | ------------------------------------ |
| `length()`                    | 字符个数  | `"abc".length()` → 3                 |
| `isEmpty()`                   | 是否空串  | `"".isEmpty()` → true                |
| `equals(Object o)`            | 比内容   | `"abc".equals("abc")` → true         |
| `replace(char old, char new)` | 替换字符  | `"abc".replace('a','x')` → "xbc"     |
| `split(String regex)`         | 按正则切割 | `"a,b,c".split(",")` → ["a","b","c"] |
| `trim()`                      | 去首尾空格 | `" abc ".trim()` → "abc"             |
| `toLowerCase()`               | 转小写   | `"ABC".toLowerCase()` → "abc"        |
| `toUpperCase()`               | 转大写   | `"abc".toUpperCase()` → "ABC"        |

# Error和Exception的区别

|       | Exception                            | Error                                   |
| ----- | ------------------------------------ | --------------------------------------- |
| 本质    | **程序级、可处理问题**                        | **系统级、JVM 级严重问题**                       |
| 能不能恢复 | 一般可以处理                               | 一般不能恢复                                  |
| 该不该捕获 | **应该捕获或抛出**                          | **不该捕获**                                |
| 典型例子  | `IOException`、`NullPointerException` | `OutOfMemoryError`、`StackOverflowError` |
| 谁的问题  | 代码逻辑 / 外部环境                          | JVM / 系统                                |
| 结果    | 可以 try-catch 后继续跑                    | 程序崩溃、退出                                 |
