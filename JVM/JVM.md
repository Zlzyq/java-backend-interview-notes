# JVM 运行时数据区有哪些？哪些线程私有、哪些共享？

JVM 运行时数据区 :方法区 堆 栈 虚拟机栈 程序计数器（只有前两个共享）


# 堆和栈的区别？各自存什么？

堆线程共享、存放对象实例和数组 （GC）
栈线程私有、存放方法调用的栈帧（局部变量表、操作数栈等）、随方法调用和返回入栈出栈。

# 怎么判断对象可回收？GC Roots 有哪些？

用可达性分析判断，从 GC Roots 出发不可达的对象才可回收，GC Roots 包括虚拟机栈中引用的对象、方法区静态属性引用的对象、常量引用的对象、本地方法栈 JNI 引用的对象等。

### 常见 GC 算法？为什么新生代用复制、老年代用标记整理？

常见 GC 算法有1. 标记2. 清除3. 复制4. 标记整理5. 分代收集
新生代对象朝生夕死、存活少所以用复制算法
老年代对象存活率高所以用标记整理或标记清除以减少复制开销。

### Minor GC / Full GC 什么时候触发？对象什么时候进老年代？

Minor GC 在新生代 Eden 满时触发
	Full GC 常在
	1. 老年代空间不足
	2. 空间分配担保失败
	3. 元空间不足
	4. 显式调用 System.gc() 时触发；
1. 对象经历多次 Minor GC 达到年龄阈值
2. 大对象直接进老年代
3. 动态年龄判定或空间分配担保时进入老年代

###  CMS 和 G1 大概流程和区别？

CMS 是标记清除式并发收集器，流程为初始标记、并发标记、重新标记、并发清除，追求低停顿但有浮动垃圾和碎片问题；G1 是面向 Region 的分代收集器，流程为初始标记、并发标记、最终标记、筛选回收，可预测停顿并支持整理，适合大堆。


### 类加载过程五个阶段？双亲委派是什么、有什么好处？

类加载过程为加载、验证、准备、解析、初始化；双亲委派是类加载器收到加载请求先委派父加载器，父加载器加载不了才自己加载，好处是避免类重复加载并保护核心类库安全。


### 线上 OOM / CPU 飙高怎么排查？会用哪些命令？

OOM 用 `jps` 定位进程、`jmap` 拿堆 dump、MAT 分析大对象和引用链，CPU 飙高用 `top -Hp` 找线程、`jstack` 看线程栈定位死循环或锁竞争，常用命令还有 `jstat` 看 GC、`jinfo` 看参数。
